# Секреты

Настоящие ключи и пароли не коммитятся.

- Локально они лежат в корневом `.env` и в `.env` сервисов. Эти файлы не попадают в git.
- На stage они лежат в GitHub Environment `stage` и в `.env` на сервере.
- TLS для локального HTTPS выпускает `./start.sh` через mkcert в `infra/certs`. Каталог в gitignore.

Если секрет попал в коммит, его нужно отозвать у провайдера. Удаление файла из последнего коммита само по себе ключ не отзывает.
