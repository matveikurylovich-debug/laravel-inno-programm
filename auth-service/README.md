# auth-service

Сервис входа платформы: регистрация, JWT, двухфакторное подтверждение и роли `admin`, `analyst`, `customer`.

Запуск всего магазина описан в корневом README. Этот сервис поднимается вместе с остальными через `./start.sh` из корня репозитория.

Первый администратор:

```bash
php artisan auth:create-admin admin@example.test
```

Если пароль не передан и терминал не интерактивный, команда печатает сгенерированный пароль один раз. Повторный запуск не создаёт второго пользователя.
